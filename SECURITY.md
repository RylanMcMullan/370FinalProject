# Security and Repository Boundaries

This is a public repository for a local password-manager application. Its intended vault contents are synthetic demonstration credentials, not accounts used in the real world.

- Work only with files in this repository and information explicitly supplied for this project. Do not inspect, copy, publish, or modify unrelated personal files, device data, tokens, or credentials.
- Use established cryptographic libraries and treat vault confidentiality and integrity as application requirements. Document security-relevant design decisions and known limitations.
- Generated sample credentials or clearly labeled sample vaults may be used for demonstrations and tests. Do not include real private credentials or secrets from the developer's environment.
- Do not introduce external services, telemetry, synchronization, or network dependencies unless approved.
- Do not claim that the software is independently audited or suitable for protecting real credentials without supporting evidence.

Report suspected vulnerabilities and unexpected security behavior to the repository owner before making substantial design changes. See `AGENTS.md` for approval and documentation rules.
