# 370 Final Project
A final project for CNIT 370 at Purdue University.

# Project Title
AI-Assisted Development and Security Evaluation of a Secure File Locker

# Project Description
For this project we will be creating a secure file locker using Python with the help of AI. The program will allow users to encrypt and decrypt files using a password. We plan to use AES-GCM encryption to protect the files and require a password to access them. We will also test the program to make sure it works correctly and use AI to help identify any security issues or vulnerabilities.
